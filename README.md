# Unity Gameplay Mechanics

Коллекция самостоятельных игровых механик на C#, реализованных для разных проектов. Каждая папка — отдельная система с кратким README и примером использования.

## Механики

- [Object Pooling](./ObjectPooling) — переиспользование объектов вместо Instantiate/Destroy
- [State Machine](./StateMachine) — конечная машина состояний
- [Inventory System](./InventorySystem) — инвентарь на ScriptableObject
- [Save / Load System](./SaveSystem) — сохранение данных в JSON
- [Generic Singleton](./Singleton) — базовый класс для синглтонов

## Стек

C#, Unity Engine, ScriptableObject-архитектура, событийная модель, дженерики.
